# BRQ | Saudi Police Mod — PRD

## Problem Statement (original)
موقع إلكتروني احترافي باللغة العربية لسيرفر FiveM سعودي للحياة الواقعية والشرطة "BRQ | Saudi Police Mod": هوية داكنة (أسود/كحلي/أخضر سعودي/ذهبي)، ترويسة باسم السيرفر + زر دخول ديسكورد + قائمة (الرئيسية، إلكتروني اختبار، القوانين، التقديم، الأخبار)، Hero تكتيكي بأزرار دخول السيرفر والديسكورد، وقسم تقديم بنموذج إلكتروني اختبار. إضافة لاحقة: ربط Discord OAuth2 بحيث يُمنح المجتاز للاختبار رتبة تلقائياً عبر بوت (Role ID: 1540339399613620255 — ✅〢مجتاز).

## Personas
- زائر/لاعب يريد الانضمام: يقرأ القوانين، يجتاز الاختبار، يربط ديسكورد، يقدّم طلب التحاق.
- مدير السيرفر: يراجع طلبات التقديم (قبول/رفض بملاحظة) وينشر/يحذف الأخبار من لوحة الإدارة.

## Architecture
- FastAPI + MongoDB (backend/server.py): auth (JWT cookie, bcrypt), quiz (أسئلة server-side + تصحيح + رمز اجتياز JWT 30 دقيقة)، applications، news، Discord OAuth2 (login/callback مع guilds.join + منح رتبة عبر Bot Token REST).
- React 19 + Vite + Tailwind v4 + framer-motion + lenis (RTL بالكامل، dir=rtl lang=ar).
- Routes: / /exam /rules /admin/login /admin (news/apply/discord/result → redirects).
